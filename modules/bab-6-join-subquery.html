JOIN & Subquery

⏱ memuat... Menengah–Lanjutan 5 soal quiz

Tujuan Pembelajaran

  • Menggunakan INNER JOIN untuk mengambil data yang cocok di dua tabel
  • Membedakan LEFT JOIN dan RIGHT JOIN beserta kasus penggunaannya
  • Menggunakan subquery di klausa WHERE, FROM, dan SELECT
  • Menerapkan EXISTS dan NOT EXISTS dalam subquery
  • Memilih antara JOIN dan subquery berdasarkan konteks query

Mengapa JOIN Diperlukan?

Setelah normalisasi (Bab 5), data kita tersebar di beberapa tabel. JOIN adalah cara SQL menggabungkan kembali data dari tabel-tabel itu dalam satu hasil query. Tanpa JOIN, kita tidak bisa menjawab pertanyaan seperti "Siapa yang sedang meminjam buku apa?" karena datanya ada di tiga tabel berbeda.

ℹ️
Analogi Sederhana

JOIN seperti menyatukan dua daftar hadir berdasarkan nama yang sama. INNER JOIN hanya ambil yang ada di keduanya. LEFT JOIN ambil semua dari kiri, tambahkan data kanan jika ada.

INNER JOIN — Data yang Saling Cocok

SQL — INNER JOIN 
-- Tampilkan daftar peminjaman aktif lengkap dengan nama anggota dan judul buku
SELECT
    a.nama_lengkap  AS Peminjam,
    a.kelas,
    b.judul         AS Judul_Buku,
    b.genre,
    p.tgl_pinjam,
    p.status
FROM peminjaman p
INNER JOIN anggota a ON p.id_anggota = a.id_anggota
INNER JOIN buku    b ON p.id_buku    = b.id_buku
WHERE p.status = 'dipinjam'
ORDER BY p.tgl_pinjam DESC;

-- Hanya anggota yang pernah meminjam (punya riwayat di tabel peminjaman)
SELECT DISTINCT a.nama_lengkap, a.kelas
FROM anggota a
INNER JOIN peminjaman p ON a.id_anggota = p.id_anggota;

LEFT JOIN — Semua dari Kiri, Plus Pasangannya

SQL — LEFT JOIN 
-- Semua anggota, TERMASUK yang belum pernah meminjam
-- (anggota tanpa peminjaman → kolom dari tabel peminjaman akan NULL)
SELECT
    a.nama_lengkap,
    a.kelas,
    COUNT(p.id_pinjam) AS total_pinjam
FROM anggota a
LEFT JOIN peminjaman p ON a.id_anggota = p.id_anggota
GROUP BY a.id_anggota, a.nama_lengkap, a.kelas
ORDER BY total_pinjam DESC;

-- Temukan anggota yang BELUM PERNAH meminjam (LEFT ONLY)
SELECT a.nama_lengkap, a.kelas
FROM anggota a
LEFT JOIN peminjaman p ON a.id_anggota = p.id_anggota
WHERE p.id_pinjam IS NULL;  -- NULL = tidak ada pasangan di tabel kanan
💡
Trik "LEFT ONLY"

Pola LEFT JOIN ... WHERE kanan.PK IS NULL sangat berguna untuk menemukan data di satu tabel yang tidak punya pasangan di tabel lain — misalnya buku yang belum pernah dipinjam, atau anggota yang tidak aktif.

Subquery — Query di Dalam Query

Subquery (nested query) adalah SELECT yang diletakkan di dalam perintah SQL lain. Ada tiga posisi penempatan:

Subquery di WHERE

SQL — Subquery di WHERE 
-- Buku yang stoknya di atas rata-rata
SELECT judul, stok
FROM buku
WHERE stok > (SELECT AVG(stok) FROM buku);

-- Anggota yang PERNAH meminjam buku genre 'Teknologi'
SELECT nama_lengkap, kelas
FROM anggota
WHERE id_anggota IN (
    SELECT DISTINCT p.id_anggota
    FROM peminjaman p
    JOIN buku b ON p.id_buku = b.id_buku
    WHERE b.genre = 'Teknologi'
);

-- Buku yang BELUM PERNAH dipinjam (NOT IN)
SELECT judul, pengarang
FROM buku
WHERE id_buku NOT IN (
    SELECT DISTINCT id_buku FROM peminjaman
);

Subquery di FROM (Derived Table)

SQL — Derived Table 
-- Rata-rata jumlah peminjaman per anggota
SELECT AVG(total) AS rata_pinjam_per_anggota
FROM (
    SELECT id_anggota, COUNT(*) AS total
    FROM peminjaman
    GROUP BY id_anggota
) AS stat_pinjam;
-- Subquery di FROM harus diberi alias (AS stat_pinjam)

EXISTS vs IN — Mana yang Lebih Cepat?

SQL — EXISTS 
-- EXISTS: lebih efisien untuk tabel besar
-- (berhenti mencari begitu ketemu satu baris yang cocok)
SELECT nama_lengkap
FROM anggota a
WHERE EXISTS (
    SELECT 1 FROM peminjaman p
    WHERE p.id_anggota = a.id_anggota
    AND p.status = 'terlambat'
);

-- NOT EXISTS: anggota yang tidak punya peminjaman terlambat
SELECT nama_lengkap
FROM anggota a
WHERE NOT EXISTS (
    SELECT 1 FROM peminjaman p
    WHERE p.id_anggota = a.id_anggota
    AND p.status = 'terlambat'
);
