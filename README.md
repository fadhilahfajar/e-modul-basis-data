# 📚 E-Modul Interaktif Basis Data

E-Modul pembelajaran Basis Data berbasis web untuk **SMK PPLG Kelas XI**,
Kurikulum Merdeka Belajar — Fase F.

## ✨ Fitur
- 7 Bab materi terstruktur (Pengenalan DB → ERD → DDL → DML → Normalisasi → JOIN → Objek Lanjutan)
- SQL Playground interaktif (jalankan query langsung di browser via sql.js)
- Quiz per bab dengan feedback langsung & progress tracker
- Game edukasi **Query Ninja** — latih logika SQL AND/OR/NOT
- Glossarium 60+ istilah dengan pencarian real-time
- Dark mode, mode cetak, responsif mobile

## 🛠️ Tech Stack
`HTML5` · `Tailwind CSS` · `Vanilla JavaScript` · `sql.js (SQLite/WASM)` · `Canvas API` · `Prism.js`

## 🚀 Cara Menjalankan
Clone repo ini, lalu buka `index.html` langsung di browser — tidak ada instalasi atau build process.

```bash
git clone https://github.com/fadhilahfajar/e-modul-basis-data.git
cd e-modul-basis-data
```

## 📁 Struktur Folder

e-modul-basis-data/
├── index.html ← Beranda / Dashboard
├── glossarium.html ← Kamus Istilah Database
├── modules/ ← 7 halaman bab materi
├── game/ ← Game Query Ninja
└── assets/
├── css/custom.css ← Design system & dark mode
└── js/ ← 8 modul JavaScript
